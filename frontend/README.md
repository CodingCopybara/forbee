## How To Run

1. Install node modules

```
nvm install 20.18.1 // node-version change
npm install



(((최미소는 이게 필요했음)))
npm install @iconify/tools --save-dev 
npm install @iconify-json/mdi --save-dev


```

2. Run Frontend Server

```


cd frontend
npm run dev
```



3. dist/ 폴더 만드는 방법

npm install  
npm run build
